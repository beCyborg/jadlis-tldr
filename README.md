# Материал посмотрен или прочитан, а через неделю от него не осталось ни строчки — и вернуться некуда

Субтитры видео или текст файла проходят через одну и ту же рамку разбора — суть, ключевые идеи,
что делать, ограничения — и ложатся отдельной заметкой в твою папку, а не остаются в переписке.

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
claude plugin install jadlis-tldr@jadlis
```

Ключей и подписок не нужно: субтитры берутся публичным путём, зависимость плагин ставит себе сам.

![Ссылка на видео и файл сходятся в одну рамку разбора, из неё выходит markdown-заметка](docs/img/hero-jadlis-tldr.webp)

Текстом: слева два входа — ссылка на YouTube и путь к файлу, — посередине общая рамка разбора,
справа готовая заметка в папке, которую ты указал при установке.

Это моё рабочее место, выложенное как есть, а не продукт: чем перестал пользоваться — убрал.

## Как это работает

![Ссылка или файл на входе, снятие субтитров или чтение файла, общая рамка разбора, заметка на выходе](docs/img/how-jadlis-tldr.webp)

На входе — ссылка на YouTube или путь к файлу, вторым словом можно задать язык заметки.
Внутри — субтитры снимает отдельный скрипт, файл читается целиком, дальше оба пути сходятся
в одну рамку разбора.
На выходе — заметка в твоей папке и её абсолютный путь в ответе.

Текстом: ссылка или файл → субтитры либо чтение файла → разбор «суть, ключевые идеи, что делать,
ограничения» → markdown-заметка с тегами в `TLDR_SAVE_DIR`.

Ставит зависимость сам плагин: хук `SessionStart` разворачивает изолированный venv в своей папке
данных и сверяет `requirements.txt` с кэшированной копией — совпало, хук молча выходит, поэтому
установка идёт один раз, а не каждую сессию. В venv лежит один пакет, `youtube-transcript-api`.
`yt-dlp` туда не ставится: это внешний бинарник, и фоллбэк на него включается, только если он уже
есть в системе.

Подстраивается разбор под объём: короткий текст сводится к сути и списку действий, на длинном
видео скилл заранее предупреждает, что нюансы могут потеряться. Из YouTube понимает четыре формы
ссылки — `watch?v=`, `youtu.be`, `shorts`, `live`, — а хвост плейлиста отбрасывает. Файлы берёт
по расширению: `.md`, `.txt`, `.html`, `.pdf`, `.org`, `.rtf`, `.csv`, `.json`, `.xml`.

## Установка и первый запуск

**а) Текст для вставки агенту.** Скопируй целиком в чат Claude Code:

```
Ты — установщик. Поставь на этот Mac плагин jadlis-tldr из маркетплейса jadlis.
Ключи этому плагину не нужны, ничего секретного спрашивать не надо.
Сначала спроси меня, в какую папку складывать выжимки, и подставь её вместо ~/tldr
во второй команде — можно указать путь внутрь Obsidian-хранилища.
Выполни ровно эти команды, дословно, ничего не сокращая:
1. claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
2. claude plugin install jadlis-tldr@jadlis --config TLDR_SAVE_DIR=~/tldr
3. claude plugin list — покажи мне строку про jadlis-tldr и его версию.
Потом скажи мне одной строкой: перезапусти Claude Code — зависимость разворачивается
хуком при старте сессии.
Перед каждой командой покажи её мне целиком и дождись «да». Сказал «нет» — не выполняй,
скажи, что именно пропустил, и иди дальше.
Команда вернула ошибку — остановись, покажи вывод, к следующей не переходи.
```

**б) Команды руками.**

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
claude plugin install jadlis-tldr@jadlis
claude plugin list
```

Первая команда ничего не ставит — она добавляет маркетплейс. Ставит только вторая, и снимается
она одной строкой: `claude plugin uninstall jadlis-tldr@jadlis --keep-data`.

Папку для заметок задаёт `TLDR_SAVE_DIR`, и передаётся она прямо в установку — `claude plugin
install jadlis-tldr@jadlis --config TLDR_SAVE_DIR=~/Заметки/tldr`. Не задал — заметки идут в `~/tldr`.
Поменять папку позже можно через `/plugin` → jadlis-tldr → настройки: на уже установленном плагине флаг
`--config` молча ничего не меняет (проверено 07.09.2026), так что второй путь — переустановка.

**в) Короткая команда.** Открой Claude Code в папке, где работаешь, и набери:

```
/jadlis-tldr:tldr https://www.youtube.com/watch?v=VIDEO_ID
/jadlis-tldr:tldr ~/Downloads/статья.pdf en
```

Не находится — сверь имя строкой `claude plugin list`. Второй аргумент — язык заметки: без него
русский, `en` даёт английский. Первый запуск делай после перезапуска Claude Code: хук ставит
зависимость на старте сессии.

## Границы, стоимость, обновление

**Чего не делает.** Не слушает звук и не распознаёт речь: субтитров нет — разбирать нечего, скилл
так и скажет и остановится. Не скачивает видео и не отдаёт дословную расшифровку — на выходе
только разбор. Не ходит на другие видеоплощадки: понимает ссылки YouTube и ничего кроме.
Не распознаёт сканы — из PDF читается текстовый слой. Не проверяет автора: что сказано
в материале, то и попадёт в заметку, отдельно отмечаются только слабые места его рассуждения.
Не правит уже сохранённую заметку — при совпадении имени кладёт рядом новую.

**Что нужно.** Ключей не нужно, подписок на сторонние сервисы тоже: субтитры берутся публичным
путём. Нужен `python3` в системе — им хук разворачивает venv и ставит туда
`youtube-transcript-api`. `yt-dlp` необязателен, в `requirements.txt` его нет и плагин его не
ставит: поставишь сам — появится запасной путь на случай, когда YouTube блокирует запрос по IP.
Папка для заметок — `TLDR_SAVE_DIR`, без неё `~/tldr`.

[уточнить] — минимальная версия `python3` в репозитории не зафиксирована.

**Порядок расхода токенов.** Прогон лёгкий: субагентов и фан-аутов здесь нет, за один заход текст
проходит через модель однажды. Дороже прочего обходится длинный материал — субтитры уходят
в контекст целиком, и на длинной записи скилл предупреждает об этом сам.

**Проверено там, где я работаю:** мой Mac, моя подписка. Где ещё это работает — [уточнить].

**Условия использования.** Лицензии нет: все права сохранены за автором. Читать и
пользоваться лично можно. Коммерческое использование, переиздание и включение в свои
продукты — по договорённости со мной.

**Обновление.** У стороннего маркетплейса авто-обновление на твоей стороне выключено: пока не
запустишь первую команду, у тебя остаётся та версия, которую ты поставил.

```
claude plugin marketplace update jadlis
claude plugin update jadlis-tldr@jadlis
claude plugin list
```

Переустановка, если что-то встало криво:

```
claude plugin uninstall jadlis-tldr@jadlis --keep-data && claude plugin install jadlis-tldr@jadlis
```
