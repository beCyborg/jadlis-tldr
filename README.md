# tldr — выжимка из видео и текстовых файлов

Плагин для Claude Code: скачивает субтитры YouTube-видео или читает локальный файл и возвращает применимую пользу — суть, ключевые идеи, что делать, ограничения.

## Зачем

Часовое видео и статья на сорок экранов стоят одинаково дорого — час внимания, из которого пригодятся три абзаца, а какие именно, заранее не видно.

Плагин снимает субтитры (ручные или автоматические) или читает файл целиком и вытаскивает применимое: не пересказ по порядку, а что из этого можно сделать и где автор оговорился.

Результат сохраняется отдельной markdown-заметкой с осмысленным именем и тегами — в свою папку или прямо в Obsidian-vault.

## Как поставить

Открой Claude Code и вставь этот блок в строку ввода:

```
Ты — установщик. Выполни ровно эти шаги и ничего сверх них:
1. Bash: claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
2. Bash: claude plugin install tldr@jadlis --config TLDR_SAVE_DIR=~/tldr
3. Скажи мне одной строкой: «Перезапусти Claude Code — хук развернёт venv с зависимостью».
```

Те же две команды руками, если Bash в приложении недоступен:

```bash
claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
claude plugin install tldr@jadlis --config TLDR_SAVE_DIR=~/tldr
```

Старый маркетплейс репозитория (`youtube-tldr-plugin`) остаётся для уже сделанных установок — после переименования репозитория они продолжают работать.

Полный HTTPS-URL — защита от клона по SSH: shorthand `owner/repo` уходит на SSH, а SSH-ключа на GitHub у нового пользователя обычно нет.

**Куда сохранять.** `TLDR_SAVE_DIR` — обычная папка, можно указать путь внутри Obsidian-vault; без настройки выжимки идут в `~/tldr`. Задать позже — `/plugin` → tldr → настройки.

**Зависимость.** `youtube-transcript-api` ставится сама в изолированный venv плагина хуком `SessionStart` при первом старте сессии. Нужен `python3` 3.8+; `yt-dlp` (`brew install yt-dlp`) — опциональный фоллбэк при блокировках YouTube.

## Как пользоваться

Команда скилла с ссылкой или путём:

```
/tldr:tldr https://www.youtube.com/watch?v=VIDEO_ID
/tldr:tldr https://youtu.be/VIDEO_ID en
/tldr:tldr ~/Downloads/статья.pdf
```

- **Видео.** Поддерживаются `youtube.com/watch?v=…`, `youtu.be/…`, `youtube.com/shorts/…`, `youtube.com/live/…`. Второй аргумент — язык вывода: `ru` по умолчанию, `en` вторым значением.
- **Файлы.** `.md`, `.txt`, `.html`, `.pdf`, `.org`, `.rtf`, `.csv`, `.json`, `.xml` — читаются как текст.
- **Результат.** Заметка `.md` с тегами в `TLDR_SAVE_DIR`, структура «Суть → Ключевые идеи → Что делать → Ограничения».

## Границы и стоимость

- **Оплаты нет.** Плагин бесплатный, API-ключей не требует; расход — только токены сессии на разбор текста.
- **Видео нужны субтитры** (ручные или автоматические): плагин работает с текстом CC, звук он не слушает. Нет субтитров — разбора не будет.
- **Файлы читаются как текст.** Из PDF берётся текстовый слой; сканы и картинки не распознаются.
- **YouTube иногда блокирует запрос** по IP: подождать и повторить, включить VPN или поставить `yt-dlp` как фоллбэк.
- **«Не установлен youtube-transcript-api»** — перезапусти Claude Code, хук развернёт venv сам; вручную: `pip install youtube-transcript-api`.

## Обновление

У сторонних маркетплейсов авто-обновление у получателя выключено по умолчанию — новая версия приезжает по команде:

```bash
claude plugin update tldr@jadlis
```

Либо один раз включить авто-обновление: `/plugin` → **Marketplaces** → `jadlis`. Ставил из `youtube-tldr-plugin` — подставляй его вместо `jadlis`. Версия задана semver'ом в `plugin.json`, история — [CHANGELOG.md](CHANGELOG.md).
